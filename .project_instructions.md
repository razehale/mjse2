# Screen to Sky (S2S) - PPL Flight Training Platform

## Project Overview
Flight training platform for X-Plane simulator. Students progress through 17 lessons across 5 arcs, uploading telemetry CSV data for automated scoring and debrief analysis.

## Tech Stack
- App Router architecture with server/client component separation
- PostgreSQL via Prisma ORM
- NextAuth.js v4 with JWT + Credentials provider
- Recharts for debrief visualization
- Framer Motion for animations
- S3 for telemetry CSV storage

## Visual Style
- Dark theme: navy gradient (#0a1628 → #0f1f3d)
- Accent: #60B5FF (sky blue)
- Arc colors: Arc1=#60B5FF, Arc2=#80D8C3, Arc3=#FF9149, Arc4=#FF6363, Arc5=#A19AD3
- Admin accent: purple-400/500
- Fonts: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (data)

## User Roles
- STUDENT: Standard progression with gate logic
- ADMIN: Full bypass, force complete, readiness flags, raw telemetry debug
- Admin account: admin@s2s.com / S2SA123

## Database Models
User, Lesson, Quiz, FlightSession, Attempt, Score, UserProgress + NextAuth models

## Gate Logic (Hub Rule)
- Previous lesson: flight_score >= 3 AND quiz_passed AND debrief_viewed
- Check flights (L4, L7, L10, L14) require associated quiz
- Admin bypasses all gates

## Key Routes
- /login, /dashboard (Path View), /lesson/[num] (4 tabs), /admin
- API: /api/lessons, /api/sessions, /api/quiz/submit, /api/progress/*, /api/admin/*

## Core Services — S2S Scoring Engine (lib/s2s-engine/)
TypeScript port of the Python s2s_scoring_engine module. Production runs pure Node.js — no Python.
- **constants.ts**: V-speeds, KHMP airport data, arc tolerances, geo helpers
- **rubrics.ts**: MetricResult, PhaseResult, SafetyFlag, LessonResult types + scoring utilities
- **telemetry-parser.ts**: CSV parser (handles FlyWithLua repeated headers), 1Hz linear-interpolation resampling
- **phase-detector.ts**: Flight phase detection (taxi, takeoff, climb, downwind, base, final, landing, T&G, stall, steep turn, slow flight)
- **arc1-grader.ts**: Full L1-L4 grading logic (gradeL1–gradeL4)
- **arc-stubs.ts**: L5-L17 stub grader returning LESSON_NOT_IMPLEMENTED
- **json-formatter.ts**: toDict/toJson matching Python output schema
- **html-generator.ts**: toHtml generating styled debrief HTML report
- **index.ts**: Main entry `evaluateFlight(csvText, lessonId, filename, opts)` → { result, json, html }

## Ground School + Quiz Architecture (ST-802B/C/D)
- **DB Models**: GroundSchoolContent (@unique lessonNum), QuizSeed (lessonNum + question), QuizAttempt (userId + lessonNum + results)
- **API Routes**: /api/ground-school/[lessonNum], /api/quiz-seeds/[lessonNum] (strips answers), /api/quiz-seeds/submit
- **UI Tabs**: Ground School tab (when groundSchoolReady=true), Quiz tab from QuizSeed (when quizReady=true), legacy Quiz tab as fallback
- **Debrief Reveal**: "What You Just Learned" section appears only after debrief marked viewed, fetches debriefReveal from GroundSchoolContent
- **Gate Logic**: Dynamic — checks QuizSeed existence per lesson. If quiz seeds exist, quizPassed required. Updated in debrief-viewed route + quiz-seeds/submit route.
- **Helpers**: lib/s2s-engine/ground-school.ts, lib/s2s-engine/quiz.ts
